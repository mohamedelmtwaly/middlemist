تقرير مصادر صور التصنيفات في المتجر
================================================================================

## ملخص:

المشروع يستخدم ثلاثة مصادر للصور مع الأولوية:
1. **الأولوية العليا:** `categories.image_url` من Supabase Storage
2. **الأولوية الثانية:** صور محلية من مجلد assets/products (fallback)
3. **الأولوية الثالثة:** صورة hero افتراضية (للصفحة الرئيسية فقط)

---

## 1. الصفحة الرئيسية (src/routes/index.tsx)

**السطر 705:**
```javascript
<img src={c.image_url ?? categoryImages[c.name_ar] ?? hero} alt={c.name_ar} />
```

**الأولوية:**
1. `c.image_url` - من قاعدة بيانات Supabase (categories table)
2. `categoryImages[c.name_ar]` - من store-data.ts (صور محلية)
3. `hero` - من assets/hero.jpg (صورة افتراضية)

**الغرض:**
عرض التصنيفات الـ15 في الصفحة الرئيسية

## 5. مصدر الصور من Supabase Storage

### رفع صور التصنيفات (src/lib/use-admin-categories.ts):

**السطر 27-64:**
```javascript
export async function uploadCategoryImage(file: File): Promise<string> {
  // ...
  const filename = `category-${timestamp}-${random}.${extension}`;
  
  // Upload to Supabase Storage
  const { data, error } = await supabase.storage
    .from('product-images')
    .upload(filename, file, {
      upsert: false,
      contentType: file.type,
    });
  
  // Get public URL
  const { data: { publicUrl } } = supabase.storage
    .from('product-images')
    .getPublicUrl(filename);
  
  return publicUrl;
}
```

**المسار في Supabase Storage:**
- Bucket: `product-images`
- مسار الملف: `category-{timestamp}-{random}.{extension}`
- مثال: `category-1732123456789-a1b2c3d.jpg`

**الرابط العام:**
```
https://rgnpxovzbwzfofbbsaja.supabase.co/storage/v1/object/public/product-images/category-{timestamp}-{random}.{extension}
```

## 6. الحقول المستخدمة في قاعدة البيانات

### جدول categories (Supabase):
- `image_url` (string | null) - رابط الصورة من Supabase Storage
- `name_ar` (string) - اسم التصنيف بالعربية
- `name_en` (string | null) - اسم التصنيف بالإنجليزية
- `slug` (string | null) - slug للتصنيف
- `is_active` (boolean) - حالة النشاط
- `sort_order` (number) - ترتيب العرض
- `parent_id` (string | null) - معرف التصنيف الأب

## 8. ملاحظات مهمة:

### 8.1 أسماء تصنيفات قديمة في fallback:
- "الورد والشوكولاتة" - غير موجود في قاعدة البيانات الجديدة
- "باقات الورد والهدايا" - غير موجود في قاعدة البيانات الجديدة

### 8.2 الصور المحلية:
- موجودة داخل المشروع في `src/assets/products/`
- يتم بناؤها تلقائياً في build و served من static assets
- ليست في Supabase Storage

### 8.3 الصور من Supabase:
- يتم رفعها عبر لوحة الإدارة
- تخزن في bucket `product-images`
- الروابط تبدأ بـ: `https://rgnpxovzbwzfofbbsaja.supabase.co/storage/v1/object/public/product-images/`

### 8.4 الأولوية في العرض:
1. إذا `categories.image_url` ليس null → استخدام رابط Supabase
2. إذا `categories.image_url` هو null → استخدام الصورة المحلية من fallback
3. (الصفحة الرئيسية فقط) إذا لا يوجد fallback → استخدام hero.jpg

---

## 9. الخلاصة:

**المصدر الأساسي:** Supabase Storage (categories.image_url)

**المصدر الاحتياطي (Fallback):** صور محلية من src/assets/products/

**الموقع:**
- Supabase Storage: `product-images/category-{timestamp}-{random}.{extension}`
- المشروع المحلي: `src/assets/products/*.jpg`

**الحالة الحالية:**
- لوحة الإدارة ترفع صور إلى Supabase Storage
- الصفحة الرئيسية ولوحة الإدارة تستخدم image_url أولاً
- إذا لم يوجد image_url، تستخدم الصور المحلية
- الصور المحلية موجودة في المشروع وليست في Supabase
