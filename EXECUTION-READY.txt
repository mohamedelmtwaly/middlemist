## المتطلبات المتبقية قبل التنفيذ:

### 1. التحقق من image_url يقبل NULL
```sql
SELECT column_name, is_nullable
FROM information_schema.columns
WHERE table_schema = 'public'
  AND table_name = 'products'
  AND column_name = 'image_url';
```

إذا كانت is_nullable = NO، نفذ:
```sql
ALTER TABLE public.products ALTER COLUMN image_url DROP NOT NULL;
```

### 2. رفع placeholder.svg إلى Supabase Storage
- المسار: product-images/placeholder.svg (جذر Bucket)
- استخدم Supabase Dashboard: Storage > product-images > Upload

### 3. تثبيت الدالة في Supabase
- افتح Supabase SQL Editor
- انسخ محتوى migration-function.sql بالكامل
- نفذ SQL
