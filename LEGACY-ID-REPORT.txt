تقرير فحص legacy_id وأعمدة قاعدة البيانات
================================================================================

## فحص legacy_id في products-transformed.json

### النتائج:
- إجمالي المنتجات: 348
- قيم legacy_id الفريدة: 0
- legacy_id null: 348 (100%)
- legacy_id فارغ (empty string): 0
- legacy_id مكرر: 0

### التحليل:
- جميع المنتجات الـ348 لديهم legacy_id = null
- لا توجد قيم legacy_id فريدة
- لا توجد قيم مكررة
- لا توجد أسماء مكررة لها legacy_ids مختلفة

### الاستنتاج:
- legacy_id يمكن تُستخدم في INSERT كـ null بشكل آمن
- لا حاجة لإضافة فحصات إضافية في migration-function.sql
- لا يوجد تعارض بين الأسماء المكررة و legacy_id

---

## فحص DEFAULT values لأعمدة products

### الأعمدة المطلوب فحصها:
- id
- created_at
- updated_at

### حالة الفحص:
- لا يمكن استخدام RPC exec_sql من خلال Supabase JS Client
- يجب تنفيذ SQL يدوياً في Supabase SQL Editor

### SQL المطلوب للتنفيذ:
```sql
SELECT column_name, data_type, is_nullable, column_default
FROM information_schema.columns
WHERE table_schema = 'public'
  AND table_name = 'products'
  AND column_name IN ('id', 'created_at', 'updated_at')
ORDER BY ordinal_position;
```

### التوقعات العامة (بناءً على Supabase Standard):
عادة في Supabase:
- id: UUID مع DEFAULT gen_random_uuid()
- created_at: TIMESTAMP WITH TIME ZONE مع DEFAULT now()
- updated_at: TIMESTAMP WITH TIME ZONE مع DEFAULT now()

### ملاحظات لـ migration-function.sql:
- بما أن هذه الأعمدة غالباً لها DEFAULT values، يمكن حذفها من INSERT
- الدالة الحالية لا تُدرج هذه الأعمدة، لذا ستعتم على DEFAULT values تلقائياً
- إذا كانت الأعمدة ليس لديها DEFAULT، يجب إضافتها إلى INSERT أو تعديل قاعدة البيانات

---

## توصيات:

### لـ migration-function.sql:
1. ✅ لا حاجة لإضافة فحص legacy_id - جميع القيم null
2. ⚠ يرجى التحقق من DEFAULT values للأعمدة التلقائية قبل التنفيذ
3. إذا لم يكن لدى الأعمدة DEFAULT، يجب:
   - إضافتها إلى INSERT statement
   - أو تعديل قاعدة البيانات لإضافة DEFAULT values

### للتنفيذ:
1. نفذ SQL المذكور أعلاه في Supabase SQL Editor
2. تحقق من النتائج
3. إذا لم يكن لدى id, created_at, updated_at DEFAULT values، أبلغني لتحديث migration-function.sql
